# Test Templates

YAML templates for integration testing.

## Purpose

- Test each module type (FileHash, FileContent, CommandVersion)
- Test AND/OR logic
- Test multi-step templates
- Test error scenarios

## Naming Convention

```
01-file-hash.yaml         # FileHash module test
02-file-content.yaml      # FileContent module test
03-version-cmd.yaml       # CommandVersion module test
04-multi-step-and.yaml    # AND logic test
05-multi-step-or.yaml     # OR logic test
```
