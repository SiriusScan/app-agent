# Error Types

Standard error types for consistent error handling.

## Purpose

- Define common error types
- Provide error wrapping utilities
- Consistent error messages
- Error categorization

## Key Types

- `PermissionDenied` - File/command permission errors
- `FileNotFound` - Missing file errors
- `Timeout` - Operation timeout errors
- `InvalidConfig` - Configuration validation errors

## Key Files

- `types.go` - Error type definitions
- `wrap.go` - Error wrapping utilities
