# Template Executor

Template execution engine with worker pool.

## Purpose

- Execute single templates sequentially
- Execute multiple templates in parallel using worker pool
- Evaluate AND/OR detection logic
- Calculate confidence scores
- Handle timeouts and errors gracefully

## Key Files

- `executor.go` - Single template execution
- `pool.go` - Worker pool for parallel execution
- `logic.go` - AND/OR logic evaluation
- `confidence.go` - Confidence calculation
